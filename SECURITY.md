# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
The Stellar Music team takes the security of our Soroban smart contracts, financial settlement calculations, and user funds seriously.

If you believe you have discovered a vulnerability, please **DO NOT** open a public issue or discuss it in public chat channels.

Please report vulnerabilities privately by emailing:
`kingtaiwodev@gmail.com`

Include:
1. Type of vulnerability (e.g. integer rounding leak, authorization bypass, storage DOS, reentrancy).
2. Step-by-step reproduction instructions or a minimal Soroban unit test case.
3. Potential impact on contract state or token balances.

We will acknowledge receipt within 48 hours and provide updates until the issue is resolved and deployed.
